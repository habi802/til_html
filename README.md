# Header 영역 HTML 작업해 보기

header 영역이 있다.
이 영역의 `내용`별 레이아웃을 먼저 고민해 보자.
이때 사용하는 html 태그를 div라고 한다.

<태그>내용</태그>
<태그 속성="값">내용</태그>

<div>내용</div>

<div class="">내용</div>

<a href="주소" target="">내용</a>
<img src="이미지 주소" />

div
a
img

list 관련 태그

- Order List ==> <ol></ol>
- UnOrder List ==> <ul></ul>
- List Item ==> <li></li>
